# 开发文档

本目录说明 CheatBreaker 1.7.10 当前的开发与交付方式。命令中的工作目录是仓库内的 `CheatBreaker/` 子目录；文中的 `target/` 也指该子目录下的 `target/`。

- [工作流程](development-workflow.md)：环境准备、修改源码、增量编译、打包、安装、交付确认与故障排查。
- [代码规范](coding-standards.md)：Java 8、配置和 Profile、GUI、键盘与输入法、网络生命周期及打包约定。

仓库根目录的 [AGENTS.md](../AGENTS.md) 是 AI 助手的简明约束。本目录提供维护者可直接操作的详细步骤。若代码或脚本发生变化，应同步更新相关文档；以实际脚本行为为准，不把尚未执行的构建或游戏内验证写成已完成。
